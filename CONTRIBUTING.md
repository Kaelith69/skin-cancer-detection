# Contributing

Thank you for your interest in contributing to **Skin Cancer Detection**!

Please read the full contributing guide in the project wiki:

👉 **[wiki/Contributing.md](wiki/Contributing.md)**

It covers:

- Development workflow (fork → branch → PR)
- Code style (PEP 8, docstrings, type hints)
- Branch naming conventions
- Pull request review criteria
- How to report issues

## Quick Summary

```bash
# 1. Fork the repo on GitHub, then clone your fork
git clone https://github.com/<your-username>/skin-cancer-detection.git
cd skin-cancer-detection

# 2. Create a virtual environment and install deps
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# 3. Create a feature branch
git checkout -b feature/your-feature-name

# 4. Make changes, commit with Conventional Commits style
git commit -m "feat: add grad-cam visualization"

# 5. Push and open a PR against main
git push origin feature/your-feature-name
```

## Code of Conduct

Be respectful, constructive, and welcoming to contributors of all backgrounds. Criticism should target code and ideas — never individuals.
